### CARA MENJALANKAN WEBSITE

------------------------------------------------------------------------

1. Clone atau unduh repository dari:

   https://github.com/SakaLH/komodo-island

2. Ekstrak folder jika diunduh sebagai file .zip.

3. Buka file `index.html` menggunakan peramban web (browser) pilihan Anda 

   atau melalui ekstensi Live Server pada Visual Studio Code.





### MATERI YANG DITERAPKAN

------------------------------------------------------------------------

- HTML5 semantik: header, nav, main, section, article, figure, figcaption, address, footer

- Elemen teks: h1-h4, p, strong, em, small, cite, komentar HTML

- List: ul, ol, dl (dt/dd), details/summary

- Media & navigasi: img (alt, width, height, loading), link internal, anchor (#), mailto, tel, link luar (target="_blank" rel="noopener noreferrer")

- Tabel: caption, thead/tbody/tfoot, th scope, colspan, rowspan

- CSS dasar: variabel (:root), selector class/elemen/pseudo, tipografi, box model

- Flexbox: header, navigasi, kartu, galeri, split layout, footer

- Responsive: viewport meta, media query 900px dan 640px, gambar fluid, tabel dapat digeser

- Embedded font: @font-face dengan file woff2 lokal

- Murni Vanilla: Tanpa Bootstrap, Tailwind, JavaScript, CMS, atau template siap pakai
